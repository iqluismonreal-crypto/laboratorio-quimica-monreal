SIMULADOR DE QUÍMICA MONREAL — V10 CON TRES JUEGOS

Esta versión conserva las secciones existentes de la V9 y agrega tres juegos como módulos HTML independientes:

1. juego_estados_agregacion.html
2. juego_memorama_tabla_periodica.html
3. juego_reto_tabla_periodica.html

Los juegos se cargan desde index.html mediante iframes para aislar sus estilos y JavaScript de las secciones existentes.

Todos los archivos quedan en el nivel raíz para facilitar su publicación en GitHub Pages.
